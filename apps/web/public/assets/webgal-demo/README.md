# WebGAL preview scene assets

`cafe-night.svg` and `cafe-dusk.svg` are original code-drawn SVG illustrations made for this project's engine preview. They do not contain third-party photographs, fonts, models or sample-game graphics. WebGAL loads them as textures through its native StageStateManager/PixiStage path.

Rain uses the unchanged texture and implementation in `src/engine/webgal/assets/tex/rain.png` and `Core/gameScripts/pixi/performs/rain.ts`, covered by the pinned WebGAL source and its retained notices. The preview does not import or execute the upstream `public/game` sample story, character dialogue or audio.
