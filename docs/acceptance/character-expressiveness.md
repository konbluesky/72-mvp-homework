# 角色四态辨识与默认神态调整

2026-10-31。用户反馈：状态区别过于克制，不能仅凭画面辨认；默认角色像情绪低落。按此次反馈增强实际Live2D姿态与画面提示。

## 原因

原场景把“等待某人且不愿直接解释”设为默认guarded，旧视觉规范又强调“克制”。参数映射进一步把guarded设为ParamMouthForm=-0.65、眼睛开合0.72、眉高-0.4，再叠加角色brightness0.88/saturation0.76，产生明显下撇嘴、半垂眼和压低眉毛。“戒备”的语义被画成了持续低落。这是应用的参数/调色选择，并非Haru模型文件损坏。

默认guarded仍表达谨慎，但不再强制悲伤：眼睛正常打开、眉高回正、嘴角正值。保留curious与relieved的差异。角色滤镜调为brightness0.98/saturation0.96；背景仍保留雨夜氛围。

状态与情绪继续正交；望窗/照片等已获得资格的剧情姿态仍拥有对应头部通道。只有真实录音状态才投影listening，只有实际播放器进入speaking才显示说话提示。此改动只消费既有投影，不新增录音/播放/剧情计时器。声音停止时嘴部和音量条归零。减少动态效果时保留可辨的关键姿态，关闭装饰动画与声音驱动的头肩晃动，嘴部仍跟随实际音频。
