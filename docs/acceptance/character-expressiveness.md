# 角色四态辨识与默认神态调整

## 2026-11-01：减缓说话口型抖动

原口型将 256 个音频采样的即时 RMS 直接写入开合，在 48 kHz 下只覆盖约 5 毫秒，容易随波形细小变化快速抖动。改为 2048 个采样（48 kHz 下约 43 毫秒），并在每次播放内部使用上升时间常数 70 毫秒、回落时间常数 120 毫秒的音量包络平滑；微弱底噪归零。平滑按音频时钟计算，由既有播放帧采样，不添加独立计时器。

原版 Vue 与 WebGAL 都消费同一个平滑后的音量，语音速度和音量不变。包络状态属于当前播放实例；结束、停止和打断仍同步输出零，不保留延迟闭嘴尾巴。既有音频边界测试同步改为检查渐进响应与结束归零；本轮只执行类型检查、前端生产构建、修改文件 ESLint/Prettier 与模块边界静态检查，未运行功能、E2E 或运行时测试，也未作本次播放视觉验收。

## 2026-11-01：加大思考时向上左右看的幅度

保留手扶下巴，把思考视线从小幅偏移改为明确的左上、右上交替：横向目标为 `-0.95 / 0.95`，纵向保持上方 `1`。首次换方向从原先等待 1.1 秒缩短到 0.3 秒后开始、0.5 秒时完成，随后每侧停留约 0.6 秒，转换仍使用平滑曲线。

原版 Vue 与 WebGAL 在没有剧情动作的思考状态直接采用这条已经平滑的眼神曲线，避免再叠加通用参数平滑而拖慢眼球移动；其他状态及剧情动作继续原有平滑方式。减少动态效果时固定看左上方。

本轮前端类型检查、生产构建、修改文件 ESLint/Prettier 与模块边界检查通过；未运行功能、E2E 或运行时测试套件。用户明确授权后，仅启动本地前端 `127.0.0.1:5173`，使用真实 Haru 模型比较左右上方视线，并从生产参数曲线的固定时刻导出逐帧眼神预览（`outputs/hand-calibration/thinking-gaze-preview.gif`）。确认眼球实际范围为 X/Y 各 `-1..1`，新横向目标使用约 95% 行程，向上使用最大行程。校准页不连接会话或音频，这项检查不代表真实聊天时序或 TTS 验收。

## 2026-11-01：思考改为眼神移动（历史记录）

根据实际截图，撤掉思考时的单侧眯眼、高低眉、反向眉角和下撇嘴；头部恢复接近正面、仅轻微偏转。双眼自然睁开、眉毛对称放松、嘴角中性。主要通过眼球移动表达思考：先看侧上方并停留，再移向另一侧上方，稍回中间，循环中保留停顿，避免连续绕圈像翻白眼。

眼神曲线从当前交互状态的进入时刻开始，在现有渲染帧中取样；不创建计时器、不延长思考状态，进入说话或取消后立即使用新状态的目标。减少动态效果时固定在侧上方。两个渲染入口同步采用这套表现，气泡继续关闭。

两个渲染入口共用角色 profile：倾听加大侧头与前倾，思考反向转头、上望、单侧抬眉并轻抿嘴；好奇抬眉歪头，放松时明显眯眼微笑；说话头肩随实际声音加强回应。非说话状态保持闭嘴，音频静音时不制造说话动作。Haru 使用笑眼参数；Miara 不声明不存在的笑眼参数，通过其已有的眼睛开合与嘴形表达放松。

## 2026-10-31：历史四态调整

2026-10-31。用户反馈：状态区别过于克制，不能仅凭画面辨认；默认角色像情绪低落。按此次反馈增强实际Live2D姿态与画面提示。

## 原因

原场景把“等待某人且不愿直接解释”设为默认guarded，旧视觉规范又强调“克制”。参数映射进一步把guarded设为ParamMouthForm=-0.65、眼睛开合0.72、眉高-0.4，再叠加角色brightness0.88/saturation0.76，产生明显下撇嘴、半垂眼和压低眉毛。“戒备”的语义被画成了持续低落。这是应用的参数/调色选择，并非Haru模型文件损坏。
