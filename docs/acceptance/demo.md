# 3–5 分钟演示

当前版本为真实 Live2D/Haru 技术替身；新版自动演示录像（本地留存）已完成，输出在 `outputs/acceptance/live2d/demo/`。文末旧视频是最初SVG基座的历史记录，不作为此次改造证据。

先启动无密钥Mock，浏览器进入场景。正式操作先点击或输入解锁声音；录音需localhost或HTTPS及FFmpeg。

| 时间      | 操作                         | 观察                                                 |
| --------- | ---------------------------- | ---------------------------------------------------- |
| 0:00–0:20 | 浏览场景介绍                 | 场景为主、成年Mira、明确Mock/SVG状态                 |
| 0:20–0:45 | “你在等谁？”、旅行话题       | 实际音频/字幕、思考/说话、戒备/好奇、望窗            |
| 0:45–1:05 | “我陪你坐一会儿”             | 释然表情，连续多轮                                   |
| 1:05–1:30 | 请求照片                     | 递照片、解码后可见、独立回执、雨势减弱               |
| 1:30–1:45 | 拒绝照片                     | 不触发新照片，已确认事实保留                         |
| 1:45–2:05 | 正说话时按住麦克风，松开发送 | 立即停声、旧字幕动作清除、录音真实上传、明示模拟转录 |
| 2:05–2:30 | 自动化阻断音频请求           | 重试/字幕降级；每句“读完了，继续”才确认              |
| 2:30–2:50 | 自动化阻断照片请求           | 照片失败可恢复，不提交未展示事实                     |
| 2:50–3:10 | 解除故障并继续对话           | 当前轮正常，旧结果不复活                             |

自动录像脚本：启动应用后 `npm run record:demo`，默认URL为http://127.0.0.1:5173，可用DEMO_URL覆盖。脚本通过真实浏览器UI操作、真实后端/音频调度，故障只在测试浏览器route注入，不添加产品调试入口。

录像由Playwright页面录像生成，不捕获系统音频；麦克风使用测试设备，不能当作真人听感、真实语音识别或移动真机证据。画面中的说明浮层由录制脚本添加，产品源码不包含该浮层。只有实际生成并核验的视频才列在最终验收表。

已实际录制 3分07秒MP4（本地留存），画面包含上述操作与故障恢复；无系统声音。

演示录像与截图不随源码提交。克隆仓库后须自行运行录制命令生成；录制属于运行时操作，需按AGENTS中的测试授权约束执行。
