## 如何使用

- `[x]`：代码或交付文件已存在，经过本次静态对照；**不代表本次已运行通过，也不代表用户已验收**。
- `[ ] 部分完成`：已有实现或材料，但尚未满足该条完整目标。
- `[ ] 待验收`：需要实际操作、设备或交付确认，静态阅读不能打勾。
- `[ ] 未实现`：当前未发现相应实现。可选扩展与核心要求分开统计。
- `P0`：正式交付前优先补齐；`P1`：随后完成验收或文档收口；`P2`：按需扩展。优先级是本清单的跟进建议。
- `E01` 等为文末证据索引；任务 ID 保持不变，后续更新状态和说明即可。未完成项附下一步或勾选条件。

已有验收文档只作为历史记录引用。例如 Deepgram 记录曾报告 169 项核心测试、4 项运行时测试和 13 项 E2E 通过；这些数字不是本次执行结果，不能替代当前提交的验证。
