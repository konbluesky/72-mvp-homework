## 项目背景

请你作为架构师，为一款结合实时语音、角色表演以及图片和视频等多模态内容的产品做方案设计和 MVP 实现。

请从零实现一个移动端网页适配优先的互动场景。不是传统的聊天消息列表：用户面对的是一个处于具体环境中的角色，可以通过文字或语音和角色互动；角色会说话、改变表情或动作，并根据交流过程触发场景演出。

### 3. 语音打断

- [x] 当角色正在说话时，用户应当能够开始新的语音输入并打断角色。—— 按住录音先停止当前播放，再处理新录音。

打断发生后：

- [x] 当前角色语音立即停止。—— 本地调用播放器 stop，不等待服务端响应。
- [x] 当前尚未完成的回复被取消或失效。—— AbortSignal 与轮次身份共同控制。
- [x] 尚未播放的字幕、动作和媒体事件不会继续出现。—— 取消清空队列并屏蔽旧回调。
- [x] 页面切换到倾听状态，并开始处理用户的新输入。—— 实际录音开始后切换倾听状态。
- [x] 上一轮迟到的网络响应不会覆盖当前状态或重新开始播放。—— 核对 generation、turnId 和异步所有权。

- [x] 可以使用自动语音活动检测，也可以设计明确的按住说话或点击打断交互。请在 README 中说明选择该方式的原因。—— 已采用按住说话/主动打断，README 已解释取舍。
