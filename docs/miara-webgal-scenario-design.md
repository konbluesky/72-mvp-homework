# 《今晚没有返程》：两次相遇的场景与关系节奏

2026-11-02，当前运行包 `last-lamp@4.0.0`。两次见面共 16 个开放交流段落，复用八张背景。对白由 LLM 根据本次真实交流生成，下文示例只表达创作方向，不是必须播放的台词。场景事件与分支由 Ink 控制，关系变化不以节点顺序或聊天次数授予。

完整体验目标仍为两次合计 30 分钟以上，约 32–38 分钟。快速阅读、手动推进、跳过可选活动和提前离开允许更短；当前没有真实交互时长验收，不用字数、等待时间或固定轮数证明达标。

## 人物与初识的分寸

米拉 26 岁，成年空乘，已结束执勤，以私人身份来喝咖啡；玩家也是成年人。她愿意与人聊几句，是否愿意继续，要在眼前的交流里慢慢形成。她有自己的幽默、好奇和欲望，也有不愿解释的事情；不因为对方坐下就依恋，不因对方问职业就先发制人。

对话先回答当前问题。简单问题可以简短回答，不需要每句都解释关系、期待和边界。玩笑要有人接，暧昧才逐渐多一点；没有调情时，也可以是一次舒服的普通相遇。

可以这样开始：

> 玩家：“刚下班？”
>
> 米拉：“嗯，刚忙完。想坐一会儿再回去。”
>
> 玩家：“还以为你是这里的店员。”
>
> 米拉：“不是，我也是客人。刚才看你在找位置。”

问姓名就回答姓名，问店里是否收摊就承接公开营业提示；不把这些问题转成职业审问或对玩家动机的试探。后面若聊到放凉的咖啡，对方开玩笑说她只在占座，她才可以顺着轻轻回一句。具体措辞由当下对话决定。

## 从街角到一张桌子

街角先看到仍亮灯的店面，尚未与角色接触。走近雨棚，才隔窗注意到独坐的身影；可以阅读营业提示、推门或离开。进店后先呈现大堂，再听见一句简短招呼：“你好，这边还有个空位。”

她提供空位。玩家可以先问一句，可以坐下，也可以走开；共桌不等于专门陪伴她。只有明确愿意落座才进入窗边。名字在有需要时介绍一次，职业和熟悉感依实际交流建立。

## 第一晚的八段交流

| 段落         | 交流目的与内容                                       | 可以发生的下一步           |
| ------------ | ---------------------------------------------------- | -------------------------- |
| 初次招呼     | 空位、营业提示、是否方便拼桌；礼貌有保留             | 接受空位或离开             |
| 先坐得自在   | 简单称呼、雨声、店里收起的椅子、今天刚下班           | 留在窗边，聊眼前小事       |
| 放凉的咖啡   | 口味与小习惯、玩家自己的生活片段；可选猜谜与照片     | 一起去看看风景画           |
| 走廊里的画   | 共同注意到的细节、休息日与旅行偏好                   | 回座位，或继续在画前聊     |
| 话题属于彼此 | 已主动分享的小事、音乐、散步；自然回撩或保持普通距离 | 短暂整理、继续聊或准备离开 |
| 回来以后     | 接离席前真的没说完的话；也可以换个新话题             | 在座位多聊，或去吧台       |
| 吧台停顿     | 饮品单、眼前的安排、是否还想一起走；不考核谁付钱     | 到门前准备道别             |
| 雨棚分别     | 普通道别、散步、再留片刻、另约见面                   | 按双方实际意愿选择         |

前三段让陌生人有空间观察彼此。中间两段通过具体分享形成兴趣，不固定安排吃醋、职业偏见、冒犯和道歉。后面几段容纳越来越自在的交流，也允许一直保持普通相处。

### 可选的小活动

猜谜是轻松认识，不是攻略题：米拉说“不喜欢咖啡、很会认路、经常把热饮放凉”，第三句是真的。公布答案不增加好感或心动，玩家可以不玩；游戏也可以自然变成讨论各自的小习惯。

墙上是店内无署名海岸风景画，没有人名、私人留言或感情线索。吧台只有公开饮品单，列有美式、拿铁、红茶；不编价格或未定义的点单、付款结果。海岸照片是她愿意分享的无人风景，拒绝看不会阻断相识。

### 补妆与内心独白

她说明去整理一下，玩家选择在窗边或走廊等候。镜头跟随她，玩家位置不变，也不能与镜中的她隔空聊天。

普通相处时，她只是检查妆容、整理东西，想回去接着聊。已有真实双向兴趣时，可以发现自己仍在想刚才的话，或有一点想快些回去。玩家希望保持距离时，她记得把相处放轻。补妆不自动产生依恋、焦虑或欲望，独处心声也不当作对方听过的话。

### 第一晚的关系去向

可以好好告别、散步或在最后一盏灯下多坐片刻；再次见面来自另一次双方愿意的约定。普通相处也可以想再认识一次，不强求先有浪漫。

成人暧昧、挑逗和自愿共度一夜保留。更私人的提议须有实际双向兴趣，她此刻也愿意；普通“再陪一会儿”不能被解释为性邀请。说清意向后，仍需要当前明确愿意共度这一夜，双方一起离开后的画面留白，再确认结果。私密过程不展开；这一夜不自动约定恋爱、排他性、再一次接触或下次见面。

## 第二次的八段交流

| 段落       | 交流目的与内容                       | 节奏与分寸                       |
| ---------- | ------------------------------------ | -------------------------------- |
| 约好再见   | 今天的招呼、状态、旧店关闭后的变化   | 有一点熟悉，仍看对方今天怎样回应 |
| 记得什么   | 第一次真的聊过、看过或做过的小事     | 允许记得不同，记录不足就不编原话 |
| 沿街走走   | 雨声、路灯、步速、最近的小事与小计划 | 日常、有来有往，不急着定义关系   |
| 今天的期待 | 还想做什么、想轻松或认真了解一点     | 对话触及时再说清，不发起固定盘问 |
| 雨棚歇脚   | 接没说完的话、安静听雨、一个小玩笑   | 沉默可以舒服，不自动是关系危机   |
| 普通日子   | 已聊过的兴趣，下次可试的一件小事     | 提议留给回应，不编具体排班或日程 |
| 相处距离   | 现在怎样相处舒服，是否愿意更靠近     | 具体接触逐项看双方当下意愿       |
| 街口选择   | 继续约会、轻松相处、朋友、告别或暂缓 | 她有自己的选择，没有亲密等级排名 |

如果第一次只是聊天，就从普通熟悉继续；若曾共度一夜，可以坦然承接，但不讲私密细节，也不因过去亲近省略当下意愿。玩家希望慢一点时，两人可以只并肩走；朋友路线也有完整的交流与结尾。

只有实际出现不同期待时，才形成分歧。她也说明自己的部分，允许双方没有现成答案，不把“成熟沟通”写成每段必读的长篇宣言。

## 场景素材的作用

街角与雨棚负责路过、选择与重逢；大堂负责初见；窗边承载真正的聊天；风景画走廊提供共同看的东西；公共洗手区只作独处镜头；吧台提供准备离开的自然停顿；街道承载散步、日常与告别。第二次旧店已关闭，只在门前、街角和街道活动。

自由聊天与手动推进共用服务端进度。下一步按钮表达一项可选行动或话题，不表示之前的话题已经完成，也不自动授予信任或心动。相关代码和调用顺序见[剧情导演与 LLM 会话分离](architecture/llm-directed-story-design.md)。
